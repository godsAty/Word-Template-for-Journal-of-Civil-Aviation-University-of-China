✈️ 《中国民航大学学报》Word 排版模板 (Word Template for Journal-of-Civil-Aviation-University-of-China)

📖 简介

本项目提供了一份专为《中国民航大学学报》(Journal of Civil Aviation University of China) 打造的纯净版 Word 模板（.dotx ）。 1:1 还原了官方要求的版面结构与隐性参数，旨在帮助各位硕博同学们在投稿阶段主要将精力集中在论文内容本身，告别繁琐的手动排版工作。

✨ 核心特性

📄 官方 PDF 格式转化：将学报官方提供的 PDF 排版规范 1:1 移植为可直接编辑的 Word 模板。

📐 基础结构就绪：预先调配好了跨页单栏与左右双栏的混合布局，以及页眉页脚和三线表样例。

🛡️ 安全模板格式：采用 .dotx 格式，每次打开都会自动新建空白副本，防止源文件被意外覆盖修改。

🚀 快速上手指南

下载模板：在本项目仓库中下载 模板.dotx 文件。

新建文档：直接双击该 .dotx 文件（Word 会自动为您新建一个名为“文档 1”的空白副本）。

录入内容：建议先在其他地方（如记事本）写好论文，去除所有杂乱格式后，以纯文本形式粘贴到文档对应的位置中。

一键刷格式：

选中您的段落或标题。

在 Word 顶部的 【开始】 -> 【样式】 面板中，点击对应的预设排版样式。

保存：按下 Ctrl+S，将其保存为 .docx 提交格式即可。

⚠️ 注意事项与免责声明（必读）

关于官方批注：为了保持模板界面的纯净与整洁，模板没有还原官方排版指南中的右侧红色批注，使用时仍需主要参考官网PDF文件。

查阅官方文件：排版要求可能会随期刊政策变动。在准备最终定稿时，强烈建议您对照学报官方最新发布的 PDF 格式说明源文件进行二次查阅，以确保万无一失。

保护分节符：文档的“摘要”与“正文（第一章）”之间存在一个隐藏的分节符，用于控制单双栏切换。在替换文字时，请小心不要将其删除。
